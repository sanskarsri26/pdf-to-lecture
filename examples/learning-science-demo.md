# Spaced Practice

Spaced practice distributes study sessions over time. The spacing effect improves long-term retention compared with cramming because some forgetting between sessions makes later study more effortful and useful.

\newpage

# Retrieval Practice

Retrieval practice strengthens memory by requiring active recall. Practice tests reveal gaps in understanding and make later recall easier. Feedback is important because it corrects errors before they become durable.

\newpage

# Interleaving

Interleaving means mixing different problem types during one practice session. Learners must choose an approach instead of repeating one procedure. This can feel harder during practice while improving later discrimination and transfer.
